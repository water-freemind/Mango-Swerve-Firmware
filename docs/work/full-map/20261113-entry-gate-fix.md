# 入口方向限速与调轮起步修复

历史记录：411A0C6B基于058B8D5A，曾完成验证、写入、6段校验和复位。**现已按用户要求撤销本页源码修订，源码恢复058B8D5A；本机车端未随本次源码回退改写，仍为411A0C6B。** 本页保留用于追溯，不代表当前源码启用了下列功能。此前入口问题见[日志复审](20261113-058B8D5A-entry-gate-review.md)，原部署见[烧录记录](20261113-entry-gate-flash.md)，最新源码状态见[PR交付](20261113-source-rollback-pr.md)。

## 修改

- 修复准备轮向失效：旧代码准备好组合速度后，分别裁剪沿程、横向和角速度，可能改变已准备好的逐轮方向。确定性反例中0.50降至0.05m/s时最差轮向跳变45.945°；候选采用同一比例缩放整个已准备twist，起步方向跳变为0°。
- 最初起步短时保留准备比例，指令平移速度超过0.03m/s或150ms后释放给正常反馈；不让旧方向无限保持。反馈死区内不足0.001m/s或rad/s的变化最多容忍150ms，正交安全限速及禁止方向仍精确执行；若原分量被禁止/反向，先零驱动重新调轮。
- 按危险方向规划地图限速。实际旋转车体包络越界仍硬停；朝侧边的分量继续由原法向净空限速约束，贴近侧边不再把无关的沿程速度统一压到0.05m/s。沿程方向使用自己的旋转包络净空，以0.45m/s²、0.20s延迟、5mm余量计算速度上限；20mm进入慢区、30mm退出，解除限速按0.45m/s²恢复。预测、95mm、真实短距、观测失联和遥控保护保留。
- 初始纵向入口及换垄终点收紧为8mm、1.5°，减少进入下一垄沟时携带的横差和航向偏差。树点仍保留20mm外窗、15mm内停止、400ms判稳与完整2s驻留。
- AISLE原有日志行增加 `se`，表示四轮中最大的目标/实测轮向角差（度），用于区分实际轮向未到位与上层反复重新准备。未增加周期日志行数，生产日志缓冲检查通过。

未恢复已撤销的1E12C880远距接管；未改变激光安装偏置、车体尺寸、速度档、转向零点或手动输出策略。新增底盘接口仅用于读取角差，不改变底盘门控阈值或电机参数。
