# 向机械队友确认的车体参数

> 2026-10-08。适用于本车沿用达妙 6220 转向、大疆 3508 驱动，但车体框架已有变化的情况。请机械队友提供**当前版本图纸和实测值**，写明版本、日期、单位与测量基准；待定项目可先标“待定”，不要用原 Hephaestus 数值代替。这里只收集车体与安装参数，不再重复询问已确认的电机型号。

## 优先要到的参数

| 优先级 | 请机械队友回答 | 用途和当前代码/赛题的关系 |

| 必须 | 标出车头、车尾、左、右；给出 FL/FR/RR/RL **四个转向轴在地面的投影中心**坐标，或前后轮中心距 `L`、左右轮中心距 `W`，单位 mm。若四点并非对称矩形，请给四个点坐标。 | `steer_wheel_kine.c` 当前按对称矩形计算，`assemble_chassis.c` 仍用旧值 `L=W=265.72986916 mm`；新轮位若改变，必须更新模型。当前运动学内部 `y` 正方向落在 FR/RR 一侧，服务层对外部 `vy/wz` 做符号变换，因此图纸须明确方向，不能只写“左正”。 |

## 建议的交付形式

请机械队友给一张**俯视标注图**（车头箭头、四轮转向轴中心、车体/机构外廓、测距窗口、控制板/电池位置）和一张**侧视标注图**（离地高度、传感器光轴、树/垄接触风险），附上上表的数值。注明“图纸尺寸”还是“实车测量”，若为图纸值请在装车后复测。使用同一个车体坐标原点；若原点尚未决定，可先用四轮中心矩形的几何中心，再记录各安装点相对坐标。

收到尺寸后，电控侧先做三项检查：①用新 `L/W` 校验四轮运动学；②以最大外宽和动态扫掠核对最窄 380 mm 通道，若外宽为 `B`，仅居中静态时左右各余 `(380-B)/2` mm，实际还要留定位误差和摆动空间；③在 PE 垫与地毯上标定轮速、横移、旋转和停车距离。确认结果后再修改 `firmware/src/service/assemble/assemble_chassis.c`，不能先凭猜测替换数值。
